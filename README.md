# DEE2025_coding - Programming resources that provide real-life challenges

This repository supports the Coding for Economists workshop at [DEE 2025](https://economicsnetwork.ac.uk/dee2025/). 

On this Github repository you can find the following resources:

** Coding in R **

* R_workbook_template.Rmd and R_workbook_template.html. A template workbook that contains short examples of how to use the rmarkdown environment to present coding challenges to learners.
* DataWalkThorugh_DEE2025.Rmd and DataWalkThorugh_DEE2025.html. A fully worked example of an introductory class for Coding in R as an illustration of how to use interactive elements in a workbook. 

** Coding in Python **

* Python_workbook_template.ipynb and Python_workbook_template.html. A template workbook that contains short examples of how to use the jupyter notebook environment to present coding challenges to learners.
* DataWalkThorugh_DEE2025_pypj.ipynb and DataWalkThorugh_DEE2025_pypj.html. A fully worked example of an introductory class for Coding in R as an illustration of how to use interactive elements in a workbook.

** Data files **

The workthroughs require a number of datafiles, these are:

* natural.xlsx, this contains data on natural disasters. The data come from the [The Centre for Research on the Epidemiology of Disasters (CRED)](https://www.emdat.be/)
* EDGAR_AR5_GHG_1970_2023.xlsx, this contains greenhouse gas emissions by country and year. This is the 2024 version of the [EDGAR dataset](https://edgar.jrc.ec.europa.eu/dataset_ghg2024) maintained by the European Union.
* WorldBank_population.csv, this is a file with the population for countries through time. The data come from the World Bank.
